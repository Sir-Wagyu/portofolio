# 🚀 Cara Menjalankan Website Portfolio

## Langkah-langkah:

1. **Buka Terminal/Command Prompt di folder project**

2. **Install dependencies** (hanya sekali di awal):

   ```bash
   npm install
   ```

3. **Jalankan development server**:

   ```bash
   npm run dev
   ```

4. **Buka browser dan akses**:
   ```
   http://localhost:5173
   ```

## ✅ Website sudah diperbaiki dengan:

-  ✅ Layout yang lebih sederhana dan rapi
-  ✅ Styling yang konsisten
-  ✅ Responsive design
-  ✅ All-in-one file (tidak ada komponen terpisah yang membingungkan)
-  ✅ Data sudah terintegrasi dari portfolioData.js

## 📝 Untuk customize:

-  Edit `src/data/portfolioData.js` untuk mengubah data
-  Edit `src/App.css` untuk mengubah styling
-  Ganti placeholder links dengan link asli Anda

Website sekarang sudah lebih clean dan mudah digunakan! 🎉
